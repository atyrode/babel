# Hand-off: Babel after the first fleet-scale day (2026-09-06)

For an agent picking this up cold. Every claim here has an issue or a commit
behind it; when this file and an issue disagree, the issue is newer.

## What happened, in one paragraph

The operator ran Babel's analysis loop as a "token sink" on one subscription
account (Anthropic, Opus, pinned through a Code worker wrapper on dev-01) for
about two hours, scaling from one conductor to eight parallel investigators.
It was the first time the whole path — conductor → worker → durable stores →
payload ring → shared PostgreSQL/Cellar catalog → a second machine — ran end
to end, and every seam that had never been crossed failed at once: no payload
ring existed anywhere in the fleet, the installed binary predated its own
staging fix, explorations never declared their publication closure, writes
were lost under concurrent runs, the config directory was wrong on macOS,
challenge/synthesis passes failed on stray observations, and the worker's
result form had no slot for proposals or findings. The first six were fixed
and released the same day (babel v0.2.2, v0.2.3; dotfiles pins applied on
dev-01 and the Mac). The last one is the next thing to build. ~600
hypotheses with cited evidence were produced and published; zero findings or
proposals, by construction.

## Decisions the operator made (binding)

1. **Manifold is the UI and the fleet.** Stop investing in the per-machine
   `babel web` + cross-machine sync experience; presentation and run/fleet
   supervision move into the manifold plugin. The data plane (durable
   stores, staging, shared catalog, ring, receipts) stays in Babel and is
   correct now. No interim hosted "master". — babel#178
2. **Code is an engine.** It owns model/provider/thinking, sandbox, tools. It
   must not know what a hypothesis, remedy, consolidation or objection is.
   Babel ships the per-stage output schema and instructions in the job
   document; Code runs the model against that schema and returns the JSON.
   — code#123, babel#182
3. **Every run's full agent transcript is archived**, treated like an operator
   session (different kind, different place), shown with its run; every
   inference step records its model so outputs can be weighed by cost and
   quality. — babel#177, code#121, babel#169, code#119
4. **Interrupted runs are a first-class durable record**: `interrupted` state
   with its own receipt, published as-is, listable, resumable, closable;
   loops stop through a stop file, never by signalling a process tree.
   — babel#176
5. **Nothing Babel produces may be lost.** A record the model produced and
   Babel refused to keep is the one unacceptable outcome. — babel#173 (fixed)

## Facts worth knowing before touching the code

- Babel never talks to a model. It writes a job to `code babel` over stdio
  (protocol v2), which runs omp `--mode rpc --no-session` inside bwrap on a
  tmpfs root and returns structured JSON. Model, prompt form, sandbox and
  credentials are Code's (SPEC.md §2.6, decision 18).
- Writers hold a `sync.Stager`; only `babel sync` holds a `Publisher`. A
  run's closure is declared by `run.Store.DeclareClosure` at run end (since
  #179) and published by the next `babel sync`; `babel sync` also declares
  any finished-but-undeclared run first (`DeclareFinished`).
- All durable stores share one SQLite file opened through
  `internal/durable` (`_txlock=immediate`, 60 s busy). Ten stores, ten
  connections, one process: fine at 8–12 concurrent runs, ugly (#181).
- Each run ≈ 1.3 GB RSS (sandboxed omp); dev-01 has 31 GB, so 12–16 runs is
  the ceiling. `earlyoom -m 15` kills at 15 % free.
- Recipes run as a set in cookbook order inside one run; shuffling
  `--recipe` flags does nothing. One recipe per run is what gives spread and
  short closures.
- `pkill -f <loop-script>` kills the runs inside the script's subshells.
  Stop a loop by a stop file, and let runs finish.
- The shared catalog holds two `workstation-linux` records sealed under a
  different key id (`phase-b-1`, an older ring). The current ring's key id is
  `k-20260906`. Union them when rotating (dotfiles `docs/secrets.md`).
