## Decisions that constrain the remaining work

- [Babel #178](https://github.com/atyrode/babel/issues/178): Manifold owns
  presentation and fleet/run supervision. No interim hosted master and no new
  per-machine `babel web` features; that surface remains a debugging shell.
  Durable stores, encryption, archive custody and the shared catalog remain
  Babel's responsibility. The decision is not proof that every data-plane
  defect is fixed.
- [Code #123](https://github.com/atyrode/code/issues/123) and
  [Babel #182](https://github.com/atyrode/babel/issues/182): Code owns generic
  runtime/profile/credential/containment policy. Babel owns domain tools,
  prompts, stage result schemas, validation and record creation. The native
  cutover replaced the old `code babel` wire protocol with `code engine` and
  native OMP RPC; do not restore mirrored domain structs in Code.
- [Babel #177](https://github.com/atyrode/babel/issues/177) and
  [Code #121](https://github.com/atyrode/code/issues/121): every run's full root
  and subagent transcript needs durable, archived, referenceable custody.
  Native event forwarding alone is not that guarantee. Reuse native session
  primitives and explicitly reconcile them with disposable containment.
- [Babel #169](https://github.com/atyrode/babel/issues/169) and
  [Code #119](https://github.com/atyrode/code/issues/119): record the model that
  actually answered, fallbacks and native usage, not merely profile intent or
  a second estimated accounting stream.
- [Babel #176](https://github.com/atyrode/babel/issues/176): interrupted runs
  must be durable, publishable, resumable and deliberately closable. Stop
  loops cooperatively; never signal a process tree to stop launching work.
- [Babel #173](https://github.com/atyrode/babel/issues/173): model-produced
  records must not be silently lost.
